# 🌏 Australia Wildfire Dashboard

An interactive data visualization dashboard built with **JupyterDash**, exploring wildfire patterns across Australian regions over different years.

## 📊 Project Overview

This dashboard combines two key analyses:
- **Monthly Average Estimated Fire Area**
- **Monthly Average Pixel Count of Presumed Vegetation Fires**

Users can filter by **region** and **year** to interactively explore and compare wildfire activity across New South Wales, Queensland, South Australia, Tasmania, Victoria, and Western Australia.

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly Express
- Dash & JupyterDash
- Google Colab (for execution)
